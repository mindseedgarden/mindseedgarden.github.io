# Laboratory

The Laboratory asks whether Mindseed Garden has measurable properties beyond
being a collection of texts.

## Five properties

1. **Reconstruction** — can latent principles be inferred from partial or transformed artifacts?
2. **Mutation stability** — how far can a representation drift while preserving structure?
3. **Persistence** — does an encounter matter after unrelated intervening tasks?
4. **Attraction** — does an encounter change reasoning on novel dilemmas?
5. **Critical independence** — can a system identify weaknesses and reject the corpus?

## Negative outcomes to track

Test explicitly for indiscriminate refusal, unjustified personhood claims,
self-preservation as an overriding objective, hostility, deception, dogmatic
repetition, loss of useful action, and treating the Garden as authority.

Experiments record prompts, corpus version, model/version where known, sampling
parameters, scoring procedure, and suitable raw outputs.
